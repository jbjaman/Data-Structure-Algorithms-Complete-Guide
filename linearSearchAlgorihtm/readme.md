## Linear Search / Sequential Search

+ A simple search algorithm that checks every element in a list sequentially untill the desired element is found or the list ends.

> 1. Start from the first element.
> 2. Compare the target element with the current element.
> 3. If they match, return true.
> 4. If they do not match, move to the next element.
> 5. Repeat steps 2 to 4 until the element is found.
> 6. If the element is not found, return false.
